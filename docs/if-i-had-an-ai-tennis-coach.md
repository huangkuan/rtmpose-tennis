# 如果我有个 AI 网球教练

> 本文中的“我”并非作者本人，而是基于典型网球爱好者塑造的虚构用户。

## 三十多节私教课之后，我缺的仍然是课后的那双眼睛

每次上课，我都会按时到场，把一筐球反复打完，也愿意为了一个看似很小的动作耐心练上许多次。对我来说，网球早已不是偶尔体验一下的新鲜活动。我知道击球前要充分转肩，不能等球到了身前才匆忙引拍；来球压得低时，要主动降低重心；打完也不能急着收拍，而要让随挥完整地走下去。这些话我不只听过，也确实在一堂堂课里努力做过。

我也越来越明白，知道一个要领和稳定地做到它，中间隔着大量重复。在一对一的课上，教练站在场边，常常能在两三个球之内看出我到底卡在哪里。有时他只让我把准备做早一点，有时让我暂时别管落点，先把身体转起来。那句针对当下的提醒，会让我接下来的几拍忽然变得顺畅。这也是我一直认可真人教练、愿意继续跟着教练学习的原因。

真正让我困扰的，是下课之后。独自练球时，我以为自己已经做到了，球却还是忽长忽短；我觉得某一拍特别流畅，回看视频才发现身体并没有像想象中那样协调用力。主观感觉会骗人，而手机里的整段录像，通常只能等训练结束后再一点点拖着看。等我终于找到那几个有问题的球，球场上的节奏、当时的感觉和下一次改正的机会都已经过去了。

于是，我最缺的并不是更多口令，也不是一个替我宣布动作“标准不标准”的裁判。我缺的是独自练习时仍然在场的那双眼睛：它能及时看见刚才发生了什么，给出的判断值得我相信，也愿意在一次次普通训练里持续记录，而不是只点评偶然拍到的一记好球。

## 现在的它，先学会了看见我

为了弄清这个项目走到了哪一步，我认真看过它现在的工作方式。它已经能读取摄像头里的现场画面，也能读取提前录好的录像。画面里同时出现几个人时，它会综合人物大小和离画面中心的远近，选择当时的主要观察对象。

选定观察对象后，它会估计鼻子、肩膀、手腕、膝盖和脚踝等一共 17 个身体位置，也会判断每个位置自己看得有多确定。在启用多人裁剪跟随的模式里，这些位置还会带动观察区域平滑移动，而不是让取景范围忽然跳来跳去。看不清、足够可信的位置太少时，它会重新寻找。身体靠近观察区域的一侧，而那一侧仍有原画面的空间可以纳入时，也会让它重新寻找。如果这一次贴边涉及的方向全都抵住了原画面的边界，重新寻找也看不到画外的内容。系统会记下这次情况，却不会仅仅因为这次贴边就立即再找。之后的例行检查，或再次看不清人，仍然可以让它重新寻找。即使为了观看流畅而把预览缩小，也只是屏幕上看起来变小，记录动作的原始位置并不会跟着改变。

画面上不断更新的状态，会概括最近一段时间的处理耗时、画面新旧程度、最多落后几帧，以及被替换画面的比例。至于系统为什么重新寻找、身体是否反复碰到观察区域边缘，要到运行结束后看终端里的会话总结，才会得到更细的记录。这对我意味着，将来若要在击球后马上给我建议，不仅判断要准，判断所依据的动作画面也必须足够新。

不过，这种尽量追上最新画面的做法并不是在所有模式下都会发生。只有明确启用异步摄像头或实时录像模式时，系统才会持续保留最新画面，让来不及处理的旧画面被更新的画面替换。后台的重新寻找也要另外启用，而且同一时刻只保留一个尚未完成的任务，避免旧任务不断排队、越等越旧。这些设计是在减少滞后，并不意味着没有等待，也不保证每一种使用方式都能同样及时。

所以，现在的它更像是先获得了“眼睛和注意力”：能找到当时的主要观察对象，并尽量跟上他的移动。但这种轻量跟随还不能确认前后画面里始终是同一名运动员。它也不能判断我打的是正手、反手还是发球，不能理解从准备到随挥的一整段动作，也尚未真正给出网球教学建议。能不能从“看见”走到“看懂”，再走到在合适的时机提醒我，是它以后才需要回答的问题。
