# 如果我有个 AI 网球教练

> **作者说明：**本文以目标市场中一名典型网球爱好者的用户画像为叙事身份，用第一人称展开。

## 三十多节私教课之后，我缺的仍然是课后的那双眼睛

这些一对一私教课，我每一节都上得很认真。对我来说，网球早已不是偶尔体验一下的新鲜活动：我会按时去球场，把一筐球反复打完，也愿意为了一个看似很小的动作耐心练上许多次。我知道击球前要充分转肩，不能等球到了身前才匆忙引拍；来球压得低时，要主动降低重心；打完也不能急着收拍，而要让随挥完整地走下去。这些话我不只听过，也确实在一堂堂课里努力做过。

我也越来越明白，知道一个要领和稳定地做到它，中间隔着大量重复。课上，教练站在场边，常常能在两三个球之内看出我到底卡在哪里。有时他只让我把准备做早一点，有时让我暂时别管落点，先把身体转起来。那句针对当下的提醒，会让我接下来的几拍忽然变得顺畅。这也是我一直认可真人教练、愿意继续跟着教练学习的原因。

真正让我困扰的，是下课之后。独自练球时，我以为自己已经做到了，球却还是忽长忽短；我觉得某一拍特别流畅，回看视频才发现身体并没有按想象中那样协调用力。主观感觉会骗人，而手机里的整段录像通常要等训练结束后再一点点拖着看。等我终于找到那几个有问题的球，球场上的节奏、当时的感觉和下一次改正的机会都已经过去了。

于是，我最缺的并不是更多口令，也不是一个替我宣布动作“标准不标准”的裁判。我缺的是独自练习时仍然在场的那双眼睛：它能及时看见刚才发生了什么，给出的判断值得我相信，也愿意在一次次普通训练里持续记录，而不是只点评偶然拍到的一记好球。
